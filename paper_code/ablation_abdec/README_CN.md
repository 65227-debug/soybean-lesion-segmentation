# A/B/D/E/C 消融训练复现说明

## 组别定义

| 组别 | 训练方式 |
|---|---|
| A | 仅使用 108 张人工精标图像进行监督训练 |
| B | 固定分割教师 + 置信度阈值伪标签 |
| C | EMA Mean Teacher，一致性学习基线 |
| D | 分割置信度 + 叶片空间门控 |
| E | 分割置信度 + 病种语义 LayerCAM 门控 |
| F | 既有完整双证据门控模型，用于统一对比 |

所有组使用相同的 DeepLabV3+ + MobileNetV3-Large、ImageNet 预训练初始化、
512×512 输入、随机种子、增强、优化器、60 个 epoch 和每个 epoch 98 次参数更新。
最佳权重仅按 27 张验证图像的 mIoU 选择。A/B/C/D/E 全部训练完成并冻结后，
才统一加载 37 张测试图像；测试集不参与训练、早停、阈值或模型选择。

## 已完成结果

|组别|最佳 epoch|验证 mIoU|验证病斑 IoU|测试 mIoU|测试病斑 IoU|
|---|---:|---:|---:|---:|---:|
|A|13|79.54%|52.58%|83.57%|64.22%|
|B|56|78.69%|52.14%|80.88%|58.36%|
|C|10|71.81%|40.30%|83.64%|66.71%|
|D|6|73.71%|44.16%|81.19%|61.80%|
|E|24|78.86%|52.79%|81.22%|60.10%|
|F|7|76.47%|50.86%|81.49%|62.43%|

当前单次划分不支持“完整门控 F 最优”：A/C 的测试 mIoU 和病斑 IoU 均高于 F。
C 在训练后期发生确认偏差，但统一测试使用的是第 10 轮验证最佳权重，而不是末轮权重。
验证集与测试集排序差异较大，说明 27/37 张样本以及混合来源数据的分布波动不可忽略。

论文中应把这些数字作为当前单次种子的客观结果，不应反向修改阈值来迎合已查看的测试集。
下一步应先按数据来源、病种和采集场景重新做分组/分层划分，再运行至少 3 个随机种子，
报告均值±标准差。若根据本次结果调整门控阈值，应另留新的最终测试集作确认性评估。

## 复现

从 mmsegmentation 项目根目录运行：

```bash
bash paper_code/ablation_abdec/run_abdec.sh
```

也可单独运行准备、训练或统一评测脚本。正式训练使用 `workers=4`，避免本机多进程
数据加载在高负载时出现段错误。完整阈值、损失权重和增强参数见
`ablation_config.json`。

## 输出位置

- `work_dirs/dadou_ablation_A` 至 `work_dirs/dadou_ablation_E`：最佳/末轮权重、
  逐 epoch CSV、PNG/PDF 收敛图、有效配置和训练摘要。
- `work_dirs/dadou_ablation_comparison`：统一测试 CSV、逐图指标、预测掩膜、
  叠加图、对比图和成对 bootstrap 区间。
- `data/dadou_abdec`：B/D/E 使用的统一弱图像、伪标签、像素权重和清单。
